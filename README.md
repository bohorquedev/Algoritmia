# 🧠 Ejercicios de Algoritmia

Repositorio dedicado a la práctica y fortalecimiento de la lógica de programación mediante ejercicios de algoritmia, organizados por semanas y desarrollados progresivamente.

El objetivo es mejorar el razonamiento lógico, la resolución de problemas y la comprensión de los fundamentos de la programación.

## 📂 Estructura del repositorio

El repositorio está organizado en tres carpetas, correspondientes a cada semana de práctica:

```text
📦 Ejercicios-Algoritmia/
│
├── 📁 WEEK-1/
│   ├── Ejercicios en PSeInt
│   └── Diagramas de flujo
│
├── 📁 WEEK-2/
│   └── Ejercicios en JavaScript
│
└── 📁 WEEK-3/
    ├── Ejercicios en PSeInt
    └── Diagramas de flujo
```

## 💻 Tecnologías utilizadas

- **PSeInt:** Desarrollo de algoritmos mediante pseudocódigo y representación gráfica con diagramas de flujo.
- **JavaScript:** Resolución de ejercicios utilizando lógica de programación y sintaxis del lenguaje.

## 📌 Consideraciones

- **Semana 1:** Ejercicios desarrollados en PSeInt. Cada ejercicio cuenta con su respectivo diagrama de flujo.
- **Semana 2:** Ejercicios desarrollados en JavaScript por decisión personal, con el propósito de practicar la lógica directamente en este lenguaje.
- **Semana 3:** Ejercicios desarrollados en PSeInt, cada uno acompañado de su respectivo diagrama de flujo.

## 🎯 Propósito

Este repositorio hace parte de mi proceso de aprendizaje en desarrollo de software. Cada ejercicio representa una oportunidad para practicar, identificar errores y mejorar progresivamente mis habilidades de resolución de problemas.
